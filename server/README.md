# 聊天室功能说明

这是一个基于 Vue 3 + Socket.IO 的实时聊天室应用。

## 🚀 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 启动开发环境

```bash
# 启动 Vue 开发服务器
npm run dev

# 启动聊天服务器（在新的终端窗口中）
npm run chat-server
```

### 3. 访问应用

1. 打开浏览器访问 Vue 应用（通常是 `http://localhost:5173`）
2. 点击进入"聊天室"页面
3. 输入用户名
4. 切换到"真实连接"模式（如果服务器已启动）
5. 开始聊天！

## 🔧 配置选项

### 服务器配置

- **端口**: 默认 3001，可通过环境变量 `PORT` 修改
- **CORS**: 支持多个开发服务器端口
- **消息历史**: 保留最近 1000 条消息
- **用户清理**: 30 分钟不活跃自动清理

### 客户端配置

- **服务器地址**: `http://localhost:3001`
- **自动重连**: 支持
- **消息限制**: 500 字符
- **用户名限制**: 20 字符

## 🔌 WebSocket 事件

### 客户端发送
- `user:join` - 用户加入
- `message:send` - 发送消息
- `typing:start` - 开始输入
- `typing:stop` - 停止输入
- `room:join` - 加入房间
- `room:leave` - 离开房间

### 服务器发送
- `message:received` - 接收消息
- `message:history` - 历史消息
- `user:joined` - 用户加入通知
- `user:left` - 用户离开通知
- `users:online` - 在线用户列表
- `typing:user` - 用户输入状态
- `server:shutdown` - 服务器关闭通知

## 🐛 故障排除

### 连接失败
1. 确保聊天服务器已启动
2. 检查端口是否被占用
3. 确认防火墙设置
4. 查看浏览器控制台错误信息

### 无法发送消息
1. 检查网络连接
2. 确认用户名已设置
3. 查看连接状态指示器

### 服务器启动失败
1. 检查 Node.js 版本（需要 14+）
2. 确认依赖已安装：`npm install`
3. 检查端口是否被占用
